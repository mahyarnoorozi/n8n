# اجرای اپ «جفتیما» روی آیفون (Expo Go)

سریع‌ترین راه برای دیدن اپ روی آیفون، بدون نیاز به حساب اپل. اپ در **حالت دمو**
کار می‌کند، پس بدون سرور هم همهٔ صفحه‌ها و امکانات را می‌بینی.

## پیش‌نیاز
- روی آیفون: برنامهٔ **Expo Go** را از App Store نصب کن.
- روی کامپیوتر (مک یا ویندوز): **Node.js نسخهٔ ۱۸ یا بالاتر** و **Git** نصب باشد.
- گوشی و کامپیوتر روی **یک شبکهٔ Wi‑Fi** باشند.

## مراحل
ترمینال را روی کامپیوتر باز کن و این دستورها را اجرا کن:

```bash
git clone https://github.com/mahyarnoorozi/n8n.git
cd n8n
git checkout claude/persian-pyred-red-theme-2285k2
cd joft-app
npm install
npx expo start
```

بعد از `npx expo start` یک **QR Code** در ترمینال ظاهر می‌شود:

- آیفون: اپ **دوربین** را باز کن و QR را اسکن کن → روی نوتیفیکیشن بزن تا در
  **Expo Go** باز شود.

> اگر گوشی و کامپیوتر روی یک Wi‑Fi نیستند یا اتصال LAN برقرار نشد، به‌جای دستور
> بالا این را بزن (تونل از طریق اینترنت):
>
> ```bash
> npx expo start --tunnel
> ```

## نکته‌ها
- **حالت دمو:** بدون سرور، داده‌ها روی همان گوشی ذخیره می‌شوند (پاسخ سؤال‌ها،
  خاطره‌ها و…). برای دیدن ظاهر و کارکرد کافی است.
- **اتصال واقعی دو نفره + اعلان‌ها:** نیاز به اجرای سرور (`server/`) و تنظیم
  متغیر `EXPO_PUBLIC_API_URL` دارد. راهنمای آن در `server/README.md` است.
- اگر `npm install` خطای peer داد، فایل `.npmrc` همین پوشه آن را خودکار حل
  می‌کند؛ در غیر این صورت `npm install --legacy-peer-deps` را اجرا کن.
