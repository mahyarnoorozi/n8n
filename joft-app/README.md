# جفت (Joft) — اپلیکیشن زوج‌ها و روابط 💞

اپلیکیشن موبایلِ فارسی و راست‌به‌چپ برای زوج‌ها، الهام‌گرفته از اپ **Paired** ولی
کاملاً بومی‌سازی‌شده برای کاربر ایرانی:

- 🇮🇷 **کاملاً فارسی و راست‌به‌چپ (RTL)** با فونت **وزیرمتن**
- 📅 **تاریخ شمسی (جلالی)** برای مناسبت‌ها و خاطره‌ها
- 📱 **ورود/ثبت‌نام با شمارهٔ موبایل** و کد تأیید پیامکی
- 🎨 **رنگ قالب آرام نیلی/بنفش تیره** و **رنگ برند قرمز `#EE1844`** فقط به‌عنوان اکسنت
  (دکمه‌های اصلی، قلب‌ها، نشانه‌ها) تا برنامه زننده نشود
- 📲 خروجی برای **iOS و Android** از یک کدِ واحد (Expo / React Native)
- 📐 طراحی **کاملاً واکنش‌گرا (Responsive)**

## بخش‌ها (مثل Paired و بهینه‌شده برای ایران)

| بخش | توضیح |
|------|-------|
| خانه | کارت رابطه، روزشمار «با همیم به مدت N روز»، مناسبت‌های خاص با تاریخ شمسی، سؤال امروز، کاوش موضوعی |
| سؤال روز | سؤال‌های روزانه؛ بعد از پاسخِ تو، پاسخ نیمهٔ دیگرت باز می‌شود |
| بازی‌ها | بازی‌ها و کوییزهای دونفره + مقاله‌های کارشناسی |
| خاطره‌ها | ثبت و مرور خاطره‌های مشترک روی خط زمانی |
| بیشتر | حساب کاربری، نسخهٔ ویژه، تنظیمات، خروج |

## اجرا روی سیستم

```bash
cd joft-app
npm install          # یا: pnpm install
npx expo start       # سپس با Expo Go روی گوشی اسکن کن
```

> آیکن‌ها از قبل ساخته شده‌اند. برای ساخت دوبارهٔ آن‌ها:
> `node scripts/gen-assets.js`

## خروجی گرفتن برای iOS و Android (EAS Build)

```bash
npm install -g eas-cli
eas login
eas build:configure

# اندروید (فایل APK برای تست):
eas build --platform android --profile preview

# اندروید/iOS نسخهٔ فروشگاه:
eas build --platform android --profile production
eas build --platform ios --profile production
```

برای iOS به حساب Apple Developer و برای Android به حساب Google Play نیاز است.
`bundleIdentifier` و `package` در `app.json` روی `com.joft.app` تنظیم شده‌اند.

## پیامک واقعی با کاوه‌نگار + پنل مدیریت 🔐

بک‌اندِ آماده در پوشهٔ [`server/`](server/) قرار دارد و پیامک را از طریق **کاوه‌نگار**
می‌فرستد. کلید API **هرگز داخل اپ موبایل قرار نمی‌گیرد** و فقط روی سرور و از طریق
**پنل مدیریت** وارد می‌شود.

### راه‌اندازی سرور

```bash
cd joft-app/server
npm install
cp .env.example .env          # ADMIN_PASSWORD و JWT_SECRET را تنظیم کن
npm start                     # سرور روی http://localhost:4000
```

### وارد کردن کلید API از پنل مدیریت

1. به آدرس `http://localhost:4000/admin` برو.
2. با رمز مدیر (`ADMIN_PASSWORD`) وارد شو.
3. **کلید API شخصی کاوه‌نگار** را در کادر بچسبان، نام **الگو (Template)** را وارد کن و ذخیره کن.
4. در پنل کاوه‌نگار یک «الگوی اعتبارسنجی» بساز که متنش شامل `%token` باشد،
   مثلاً: «کد تأیید شما در جفت: `%token`».

### وصل کردن اپ به سرور

در فایل `.env` کنار `app.json` آدرس سرور را بگذار:

```
EXPO_PUBLIC_API_URL=https://api.your-domain.com
```

اگر این مقدار خالی بماند، اپ در **حالت دمو** اجرا می‌شود و کد `۱۲۳۴` را می‌پذیرد
(برای دیدن و تست اپ بدون سرور).

### جریان کار

```
اپ → POST /api/auth/request-otp { phone }
        سرور: تولید کد → ارسال با کاوه‌نگار (verify/lookup) → ذخیرهٔ هش با انقضای ۲ دقیقه
اپ → POST /api/auth/verify-otp { phone, code }
        سرور: بررسی کد → صدور توکن (JWT 90 روزه)
```

ویژگی‌های امنیتی سرور: محدودسازی نرخ (هر ۶۰ ثانیه یک کد، حداکثر ۵ در ساعت)،
ذخیرهٔ هش‌شدهٔ کد، سقف تلاش، ماسک‌کردن کلید و شماره‌ها در پنل.

### سرویس‌های جایگزین پیامک

ساختار به‌گونه‌ای است که می‌توانی به‌جای کاوه‌نگار از **قاصدک**، **ملی‌پیامک**،
**SMS.ir** یا **Firebase Phone Auth** استفاده کنی؛ فقط فایل
[`server/kavenegar.js`](server/kavenegar.js) را عوض کن.

## ساختار پروژه

```
joft-app/
├─ app/                      # مسیرها (expo-router، فایل‌محور)
│  ├─ _layout.tsx            # ریشه: بارگذاری فونت، RTL، احراز هویت
│  ├─ index.tsx             # هدایت بر اساس وضعیت کاربر
│  ├─ onboarding.tsx
│  ├─ (auth)/               # phone → verify → profile
│  ├─ (tabs)/               # خانه، سؤال‌ها، بازی‌ها، خاطره‌ها، بیشتر
│  ├─ question/[id].tsx
│  ├─ game/[id].tsx
│  └─ article/[id].tsx
├─ src/
│  ├─ theme/                # رنگ، تایپوگرافی، فاصله‌ها
│  ├─ components/           # دکمه، کارت، متن، آواتار، ...
│  ├─ context/AuthContext.tsx
│  ├─ data/content.ts       # سؤال‌ها، بازی‌ها، مقاله‌ها (فارسی)
│  ├─ i18n/fa.ts            # رشته‌های رابط کاربری
│  └─ utils/                # تبدیل تاریخ شمسی و ارقام فارسی
├─ assets/                  # آیکن و اسپلش (قلب سفید روی قرمز برند)
├─ scripts/gen-assets.js
├─ server/                  # بک‌اند کاوه‌نگار + پنل مدیریت (Node/Express)
│  ├─ index.js              # اندپوینت‌های OTP و ادمین
│  ├─ kavenegar.js          # فراخوانی سرویس کاوه‌نگار
│  ├─ store.js              # ذخیرهٔ تنظیمات، کد، نرخ، لاگ
│  └─ public/index.html     # صفحهٔ پنل مدیریت (RTL)
├─ preview/index.html       # پیش‌نمایش تصویری همهٔ صفحه‌ها
├─ app.json                 # پیکربندی Expo (iOS/Android/RTL)
└─ eas.json                 # پروفایل‌های ساخت
```
