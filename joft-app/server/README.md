# بک‌اند جفت — احراز هویت پیامکی (کاوه‌نگار) + پنل مدیریت

سرور سبک Node/Express که کد یک‌بارمصرف را با **کاوه‌نگار** می‌فرستد و کلید API را
امن، روی سرور، نگه می‌دارد. کلید فقط از طریق **پنل مدیریت** وارد می‌شود و هرگز در
اپ موبایل قرار نمی‌گیرد.

## راه‌اندازی

```bash
npm install
cp .env.example .env     # ADMIN_PASSWORD و JWT_SECRET را عوض کن
npm start                # http://localhost:4000
```

پنل مدیریت: `http://localhost:4000/admin`

## متغیرهای محیطی (.env)

| متغیر | توضیح |
|-------|-------|
| `ADMIN_PASSWORD` | رمز ورود به پنل مدیریت |
| `JWT_SECRET` | کلید امضای توکن کاربران |
| `PORT` | پورت سرور (پیش‌فرض ۴۰۰۰) |
| `DEV_RETURN_CODE` | فقط تست محلی: کد را در پاسخ برمی‌گرداند (در پروداکشن خاموش) |

## اندپوینت‌ها

| متد و مسیر | کار |
|------------|-----|
| `GET /api/health` | وضعیت سرویس و این‌که کلید تنظیم شده یا نه |
| `POST /api/auth/request-otp` | `{ phone }` → تولید و ارسال کد |
| `POST /api/auth/verify-otp` | `{ phone, code }` → تأیید و صدور توکن |
| `POST /api/admin/login` | `{ password }` → ورود مدیر |
| `GET /api/admin/settings` | خواندن تنظیمات (کلید ماسک‌شده) |
| `POST /api/admin/settings` | ذخیرهٔ کلید API، الگو، روش و... |
| `GET /api/admin/logs` | آخرین درخواست‌ها (شماره ماسک‌شده) |

## تنظیم الگوی کاوه‌نگار

در پنل کاوه‌نگار یک «الگوی اعتبارسنجی» بساز که متنش شامل `%token` باشد، مثلاً:

> کد تأیید شما در جفت: `%token`

سپس همان **نام الگو** را در پنل مدیریت وارد کن.

## امنیت

- کلید API فقط روی سرور و در `data/settings.json` (در `.gitignore`) ذخیره می‌شود.
- محدودسازی نرخ: هر ۶۰ ثانیه یک کد، حداکثر ۵ در ساعت برای هر شماره.
- کدها هش‌شده و با انقضای ۲ دقیقه ذخیره می‌شوند؛ سقف ۵ تلاش برای هر کد.
- شماره‌ها و کلید در پنل ماسک می‌شوند.

## استقرار (Deploy)

این سرور را روی هر سرویس Node می‌توانی اجرا کنی (Render، Railway، یک VPS، …).
بعد از استقرار، آدرس عمومی را در فایل `.env` اپ بگذار:
`EXPO_PUBLIC_API_URL=https://...`
